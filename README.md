# Sistema de Controle de Estoque em C

Projeto desenvolvido em linguagem C para realizar o cadastro e o gerenciamento de produtos de um estoque.

## Funcionalidades

- Cadastrar produtos.
- Consultar produtos pelo código.
- Atualizar o estoque, realizando entradas e saídas.
- Listar todos os produtos cadastrados.

## Tecnologias utilizadas

- Linguagem C
- Biblioteca padrão `stdio.h`
- Biblioteca `string.h`

## Como executar

Compile o arquivo `main.c` utilizando um compilador C, como o GCC:

```bash
gcc main.c -o estoque
```

No Windows, execute:

```bash
.\estoque.exe
```

## Objetivo

Praticar conceitos fundamentais da programação em C, como estruturas, vetores, funções de entrada e saída, condicionais e laços de repetição.
